Complete Run & Integration Guide

Everything you need to run, configure, and integrate AgentShield across your local workstation, Git hooks, CI/CD pipelines, and autonomous AI agents.

🚀 1. Zero-Install Execution (npx)

Run AgentShield directly without modifying your global environment or installing dependencies.

# Audit any file or .env config
npx agentshield scan .env

# Redact exposed secrets to stdout
npx agentshield redact server.js

# Test shell interception
npx agentshield exec "cat .env"

📦 2. Local Project Installation

Install AgentShield as a development dependency for your engineering team.

# npm
npm install -D agentshield

# pnpm
pnpm add -D agentshield

# yarn
yarn add -D agentshield

🌍 3. Global CLI Installation

Have agentshield and shorthand ashield globally available across all directories.

# Install globally
npm install -g agentshield

# Verify installation

ashield --help

🧩 Programmatic TypeScript / Node.js API

Embed AgentShield redaction and sandboxing directly into custom agent frameworks, Express proxies, or LLM middleware.

import { AgentShieldEngine, AgentCommandSandbox } from "agentshield";

// 1. Initialize Engine
const shield = new AgentShieldEngine();

// 2. Sanitize LLM prompt input
const input = "Connect using postgres://admin:secret123@db:5432/main";
const result = shield.scanAndRedact(input);
console.log(result.sanitizedText);
// → "Connect using postgres://admin:[AGENT_SHIELD:GENERIC_PASSWORD:8f2a1b]@db:5432/main"

// 3. Rehydrate locally upon LLM completion
const original = shield.rehydrate(result.sanitizedText);

// 4. Test Shell Sandbox
const sandbox = new AgentCommandSandbox();
const check = sandbox.inspect("cat .env");
console.log(check.allowed); // false
