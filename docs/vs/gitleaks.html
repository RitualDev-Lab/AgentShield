AgentShield vs Gitleaks

Static git commit scanning vs real-time interactive AST execution sandboxing for autonomous AI coding agents.

Executive Summary

While Gitleaks is an outstanding static scanner for git repositories and pre-commit hooks, it operates strictly on commit histories and git diffs. Modern autonomous AI agents (such as Claude Code, Cursor, Windsurf, and Antigravity) execute commands in real-time subshells. An agent running cat .env or exfiltrating credentials over HTTP never commits those secrets to git—rendering static commit scanners blind.

AgentShield operates at the runtime execution boundary: normalizing shell commands via Abstract Syntax Tree (AST) analysis, blocking unauthorized credential reads in-flight, and redacting tokens in prompt streams using deterministic surrogate tokens.
